# Права

Мод «Good Mod», его исходный код и ресурсы (текстуры, шейдеры,
`aflArmorFlashlightSettings.swf`, нативный `afl_native.pyd`, `meta.xml`)
принадлежат автору мода — владельцу этого репозитория.

Проект не связан с Lesta Games / Wargaming. «Мир танков» — их товарный знак.

Мод работает без обращения к серверу авторизации: серверная часть отключена
флагом `OFFLINE_DEV_MODE`, проверки не подделываются, а просто не запускаются.
